# 体験記 画像編集ツール

小画像（正方形・50KB前後）と大画像（3:2・100KB前後）を、ブラウザの中だけで作るツールです。
サイズの扱いは 2026マニュアル ③-5「画素数変更」に合わせています。
画像が外部に送信されることはありません（背景ぼかしの初回のみ、ぼかし用モデルをネットから読み込みます）。

## できること
- 元画像の読み込み（ファイル選択／ドラッグ＆ドロップ／Ctrl+V 貼り付け）
- 小画像・大画像を**別々に**位置調整（ドラッグ・ホイール・スライダー）
- 頭上の余白ガイド線（表示専用。**書き出した画像には写りません**）
- 「全体を収める」で余白（白）つきにする（賞状が切れるとき用）
- 背景ぼかし＋ブラシで微調整
- サイズ調整（マニュアル準拠）：小画像15〜50KB／大画像30〜100KBに収まっていればそのまま。超えるときだけ、縦横比を保ったまま縮小して50KB／100KB以内に収めます（マニュアルの「%を小さくして規定サイズにする」に相当。毎回同じ結果）。**元画像より大きくなる書き出し（水増し）はしません**
- 元データURL末尾の数字から `12345s.jpg` / `12345l.jpg` を自動命名
- 元画像のサイズ警告（10KB以下／20KB未満＝処理対象外・要確認、20KB代＝切り取りのみ）、低解像度・過拡大の警告
- 書き出し後の自動チェック（KB・縦横比・ID有無）と、マニュアル「画像確認」の目視チェック欄

## ファイル構成
```
image-tool/
├── index.html
├── css/style.css
├── js/
│   ├── image-editor.js   ← 画像処理のコア（規格 SPECS はここ）
│   └── image-app.js      ← 画面操作
├── functions/_middleware.js   ← ID・パスワード認証（Cloudflare Pages Functions）
├── .assetsignore / .gitignore
└── README.md
```

## 規格を変えたいとき
`js/image-editor.js` の先頭にある `SPECS`（作業用の大きさ・縦横比・規定KB範囲）と `SOURCE_RULES`（元画像の警告しきい値）を編集します。
※ マニュアルが定めているのはKBと縦横比だけなので、作業用の大きさ（小720×720／大960×640px）はこのツール側の設定です。実際のサイトの表示サイズに合わせて変えて構いません。

## 公開方法

### A. 既存の体験記チェッカーのリポジトリに追加する（おすすめ・ログインもそのまま共通）
1. このフォルダの中の `index.html` `css/` `js/` を、チェッカーのリポジトリ内の新しいフォルダ（例：`image/`）にコピーする
   （`functions/` `.assetsignore` `.gitignore` `README.md` はコピーしない。チェッカー側にあるものがそのまま全体に効きます）
2. GitHubへ push
3. `https://（チェッカーのURL）/image/` で開ける。チェッカーと同じユーザー名・パスワードで入れる

### B. 単独のツールとして新しく公開する
1. このフォルダ全体を新しいGitHubリポジトリにpush（Privateを推奨）
2. Cloudflareダッシュボード → Workers & Pages → Create → Pages → Connect to Git → そのリポジトリを選択
   - Framework preset: None ／ Build command: 空欄 ／ Build output directory: 空欄（または `/`）
3. プロジェクトの Settings → Environment variables に `CHECKER_USER` / `CHECKER_PASS` を追加（**Encrypt にチェック**）
4. Deployments から再デプロイ

※ Cloudflareダッシュボードへの「ZIPのドラッグ＆ドロップ」は `functions/`（認証）に対応していないので使わないでください。
※ 環境変数が未設定のときは、安全のためサイトは開けません（503エラー）。

## 使い方（担当者向け）
1. 元データのURLを貼る → ファイル名が表示される
2. 元画像を読み込む（サイズ警告が出たら、その指示に従う。20KB未満は処理対象外／20KB代は広報部コメントに書いて切り取りのみ）
3. 小画像・大画像それぞれで、頭上にこぶし1個分の余白になるよう位置・拡大率を調整
4. 必要なら背景をぼかす（人物以外が自動でぼける。ブラシで微調整）
5. 「小画像・大画像をまとめて書き出し」→ ダウンロードされた2枚と、画面のチェック結果・目視チェックを確認
6. 管理画面にアップロード

## 動作環境
最新の Chrome / Edge / Safari / Firefox。iPhone の HEIC 形式はブラウザで開けないことがあります（JPEG/PNGで保存し直してください）。
